# Marvel Journey 2.1

## Added
- All 132 previously completed issues are now individually listed and prechecked.
- Completed History appears as its own era and can be browsed in the Library.
- One-tap **Mark complete / Mark unread** button for every collection.
- Existing Version 2.0 progress, ratings and notes migrate automatically.
- Completed-history seeding occurs only once, so you can later uncheck an item without it being rechecked on every launch.

## Upload
Replace all six files in the root of the GitHub repository:
- index.html
- config.js
- reading-lists.js
- manifest.webmanifest
- service-worker.js
- README.md
