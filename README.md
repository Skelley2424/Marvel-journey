## Saving
The app uses browser localStorage. Data belongs to the combination of:
1. the browser/device, and
2. the stable website address where the app is hosted.

Clearing site data or changing to another domain/browser can remove access to that local save. Export backups regularly.

## Install on iPhone
Host this folder on an HTTPS static site. Open the stable URL in Safari, tap Share, then **Add to Home Screen**.

## Hosting
Upload the contents of this folder to GitHub Pages, Netlify, Cloudflare Pages, or another static host.
